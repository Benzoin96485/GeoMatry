# Directional Implicit Optimizer Demos

These notebooks try `DirectionalImplicitMultipleSystemOptimizer`, which uses directional implicit gradients without exact line minimization.

- `spring_nn_from_spring/spring_nn_from_spring.ipynb`: target geometries generated by `SpringFF`, optimized model is `NNPotentialFF`.
- `spring_from_spring/spring_from_spring.ipynb`: target geometries generated by `SpringFF`, optimized model is perturbed `SpringFF`.
- `lj_from_lj/lj_from_lj.ipynb`: target geometries generated by `LJFF`, optimized model is perturbed `LJFF`.

Each case has its own folder so generated `Ra_star_*.xyz` and `Ra_star_traj.xyz` files do not overwrite outputs from another case.

The NN case is separated from the exact-line-search notebooks because exact line minimization can behave poorly for neural-network potentials.
